# Log Envanteri (Gün 4 - Tamamlanmış Hali)

| Makine / Sistem | Log Kaynağının Adı | Depolandığı Yer (Konum) | Kaydettiği Olay Türleri | Saklama Süresi / Log Rotation Mekanizması | Okuma / Sorgulama Aracı | Detaylı Açıklama & Önem |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Linux (Ubuntu)** | `systemd-journald` | `/run/log/journal/` veya `/var/log/journal/` | Çekirdek mesajları, servis durumları, genel sistem günlükleri (ikili format). | Yapılandırmaya bağlıdır (`SystemMaxUse` / `MaxRetentionSec`); disk doluluk veya zaman aşımına göre temizlenir. | `journalctl` | Modern Linux dağıtımlarında varsayılan sıkıştırılmış ikili log altyapısıdır. |
| **Linux (Ubuntu)** | Geleneksel Auth Logları | `/var/log/auth.log` (varsa) | Kimlik doğrulama, SSH giriş denemeleri, parola değişimleri. | `logrotate` ile yönetilir (genellikle haftalık rotasyon, sıkıştırılarak `auth.log.1.gz` şeklinde saklanır). | `cat`, `grep`, `less`, `tail` | Düz metin formatında tutulan kritik güvenlik log kaynağıdır. |
| **Linux (Ubuntu)** | Sudo Yetki Yükseltme | Journald / Syslog entegre | `sudo` ile gerçekleştirilen ayrıcalıklı komut çalıştırma denemeleri, hatalı şifreler. | Bağlı olduğu ana log sisteminin (`journald` / `auth.log`) rotasyon politikasına tabidir. | `journalctl _COMM=sudo`, `grep sudo` | Yetkisiz ayrıcalık yükseltme (Privilege Escalation) girişimlerini denetlemek için hayati önem taşır. |
| **Windows** | Application Log | Event Viewer / EVTX | Üçüncü taraf yazılım hata, uyarı ve bilgi mesajları. | Boyut sınırına ulaşıldığında **en eski olayların üzerine yazma** (`Overwrite oldest events`) stratejisi uygulanır. | Event Viewer (`vwr.msc`), PowerShell (`Get-WinEvent`) | Uygulama çökmeleri ve yazılım anomalilerinin takibi için kullanılır. |
| **Windows** | Security Log | Event Viewer / EVTX | Başarılı/başarısız oturum açma (`4624`, `4625`), hesap yönetimi, log silme (`1102`). | Sabit boyut sınırına ulaşıldığında eski kayıtların üzerine yazılır. Trafiğe bağlı olarak günler/haftalar saklanabilir. | Event Viewer (`vwr.msc`), PowerShell (`Get-WinEvent`) | Windows güvenliğinin kalbidir; yetkisiz erişimler ve kalıcılık analizleri için en kritik kaynaktır. |
| **Windows** | System Log | Event Viewer / EVTX | İşletim sistemi çekirdeği, sürücüler ve yerleşik servis durum/hata olayları. | Boyut sınırı dolduğunda eski kayıtların üzerine yazılır. | Event Viewer (`vwr.msc`), PowerShell (`Get-WinEvent`) | Donanım arızaları, servis çöküşleri ve şüpheli servis kurulumlarının tespiti için incelenir. |
| **Windows** | Setup Log | Event Viewer / EVTX | İşletim sistemi bileşen kurulumları ve büyük güncellemeler. | Sabit boyut sınırı; üzerine yazma politikası aktiftir. | Event Viewer (`vwr.msc`), PowerShell (`Get-WinEvent`) | Sistem kurulum süreçleri ve sürüm geçişlerinin takibinde kullanılır. |
| **Windows** | Sysmon | Event Viewer (`Microsoft-Windows-Sysmon/Operational`) | Süreç oluşturma (`ID 1`), ağ bağlantıları (`ID 3`), dosya oluşturma (`ID 11`), DNS (`ID 22`). | Yüksek log hacmi nedeniyle EVTX boyut sınırına hızlı ulaşır; limit aşımında üzerine yazılır (yoğun kullanımda kısa süre saklanır). | Event Viewer (`vwr.msc`), PowerShell (`Get-WinEvent`) | Komut satırı argümanları, ebeveyn-çocuk süreç ilişkileri ve ağ aktivitelerini izleme olanağı tanır. |
