# Log Envanteri (Gün 3)

Windows varsayılan olay günlükleriyle genişlettiğimiz log envanteri tablosuna, bugün kurduğumuz Sysmon aracı eklenmiştir:

| Makine / Sistem | Log Kaynağının Adı | Depolandığı Yer (Konum) | Kaydettiği Olay Türleri | Okuma / Sorgulama Aracı | Detaylı Açıklama & Önem |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Linux (Ubuntu / VirtualBox)** | `systemd-journald` (Journald) | `/run/log/journal/` veya `/var/log/journal/` | Çekirdek mesajları, sistem servis durumları, donanım olayları ve genel sistem günlükleri (ikili format). | `journalctl` | Modern Linux dağıtımlarında varsayılan olarak gelen, logları sıkıştırılmış ve indekslenmiş ikili formatta tutan gelişmiş günlükleme altyapısıdır. |
| **Linux (Ubuntu / VirtualBox)** | Geleneksel Auth Logları | `/var/log/auth.log` (varsa) | Kimlik doğrulama olayları, başarılı/başarısız SSH giriş denemeleri, parola değişimleri (düz metin formatı). | `cat`, `grep`, `less`, `tail` | Eski veya yapılandırılmış sistemlerde düz metin olarak tutulan, analistlerin komut satırı araçlarıyla doğrudan hızlıca tarayabildiği kritik güvenlik log kaynağıdır. |
| **Linux (Ubuntu / VirtualBox)** | Sudo Yetki Yükseltme Kayıtları | Journald / Syslog entegre | Kullanıcıların `sudo` kullanarak gerçekleştirdiği ayrıcalıklı komut çalıştırma denemeleri, başarılı yetki alımları ve hatalı şifreler. | `journalctl _COMM=sudo`, `grep sudo` | Yetkisiz kullanıcıların sistemde ayrıcalık yükseltme (Privilege Escalation) girişimlerini ve yöneticilerin hareketlerini denetlemek için hayati önem taşır. |
| **Windows** | Application Log | Event Viewer / EVTX | Üçüncü taraf yazılımların ve uygulamaların ürettiği hatalar, uyarılar ve bilgi mesajları. | Event Viewer (`eventvwr.msc`), PowerShell (`Get-WinEvent`) | Uygulama çökme raporları ve yazılım tabanlı anomalilerin takibi için kullanılır. |
| **Windows** | Security Log | Event Viewer / EVTX | Başarılı/başarısız oturum açma denemeleri (`4624`, `4625`), hesap yönetimi (`4720`, `4732`), log silme (`1102`). | Event Viewer (`eventvwr.msc`), PowerShell (`Get-WinEvent`) | Windows güvenliğinin kalbidir; yetkisiz erişimler ve kalıcılık (persistence) analizleri için en kritik kaynaktır. |
| **Windows** | System Log | Event Viewer / EVTX | İşletim sistemi çekirdeği, sürücüler ve yerleşik servisler tarafından üretilen durum/hata olayları. | Event Viewer (`eventvwr.msc`), PowerShell (`Get-WinEvent`) | Donanım arızaları, servis çöküşleri ve şüpheli servis kurulumlarının (`7045`) tespiti için incelenir. |
| **Windows** | Setup Log | Event Viewer / EVTX | İşletim sistemi bileşen kurulumları ve büyük güncellemeler (feature updates) sırasında oluşan olaylar. | Event Viewer (`eventvwr.msc`), PowerShell (`Get-WinEvent`) | Sistem kurulum süreçleri ve sürüm geçişlerinin takibinde kullanılır. |
| Makine / Sistem | Log Kaynağının Adı | Depolandığı Yer (Konum) | Kaydettiği Olay Türleri | Okuma / Sorgulama Aracı | Detaylı Açıklama & Önem |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Windows** | Sysmon (System Monitor) | Event Viewer (`Applications and Services Logs -> Microsoft -> Windows -> Sysmon -> Operational`) | Süreç oluşturma (`Event ID 1`), ağ bağlantıları (`Event ID 3`), dosya oluşturma (`Event ID 11`), DNS sorguları (`Event ID 22`) vb. | Event Viewer (`eventvwr.msc`), PowerShell (`Get-WinEvent`) | Windows varsayılan loglarının yetersiz kaldığı durumlarda; komut satırı argümanlarını, ebeveyn-çocuk süreç ilişkilerini (PPID) ve detaylı ağ aktivitelerini yakalayarak saldırı izlerini sürmemizi sağlayan kritik görünürlük aracıdır. |
